# Node pathing algorithm testing

Tests 6 variations of a node pathing algorithm, going from zero randomess added to a lot of randomness. Interesting results! At higher node values, the algorithms with a bit of added randomness do just about as well as the one with none. 

The algorithm goes from node to node by picking whichever one is closest to the one it's currently on. 

The code is very messy. I want to completely remake this project in the future.
